## 지금의 진행은 기기에 저장됩니다

게임 진행과 설정은 현재 기기에 자동 저장됩니다. 대화·조리·결과 도중 앱을 닫았다가 돌아오면 저장한 진행에서 이어집니다. 기기를 바꾸거나 앱을 삭제하기 전에는 저장 파일을 따로 내보내 주세요.

## 저장 내보내기

설정 → 저장 내보내기를 선택하고 Files 또는 원하는 공유 대상에 저장합니다. 파일을 외부 서비스에 보내면 해당 서비스의 정책이 적용됩니다. 원래 기기 밖에 보관한 파일은 사용자가 직접 관리합니다.

## 저장 가져오기

설정 → 저장 가져오기에서 유효한 JSON 저장 파일을 선택합니다. 파일 크기는 1MB 이하여야 합니다. 현재 진행을 바꾸는 확인 창을 닫으면 지금의 기록을 유지합니다.

## 진행을 읽을 수 없을 때

게임은 직전 정상 저장으로 복구를 시도하고 원본을 별도로 보관합니다. 저장 실패 안내가 나오면 내보내기로 현재 기록을 보관하고 다시 저장을 시도해 주세요. 문제가 계속되면 지원 메일에 앱 버전, 기기 모델, iOS 버전, 재현 방법을 알려 주세요.

# Add an app

Follow ADD-GAME.md, using `kind: app`. The entry appears in `/projects/` and `/apps/`, and its detail page uses SoftwareApplication structured data. Supply real platforms and store links; do not copy a game’s genre or purchase claims.

The sample `_example.json` is intentionally excluded. Remove all example product-specific copy before making a real entry. Use the shared light/dark layout and the studio illustration, or add verified app art through ProductArt. No executable files belong in this website.

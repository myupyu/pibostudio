# Pibo Studio 공개 배포 · 2026-10-15

사용자가 준비한 홈페이지·정책 공개 배포와 기존 pibostudio.com 도메인 연결을 명시적으로 승인했다. 앞선 통합 문서의 공개 보류 조건은 이 승인으로 해소되었다. 원래 StockPets 사이트와 다른 Cloudflare 서비스, 메일 DNS는 유지한다.

공개용 정적 빌드와 경로·번역·메타데이터 검사를 통과했다. 저승분식 소개·글·개인정보·지원 안내는 무료 전체 이야기, 배너, 선택적 일회성 광고 제거 및 실제 SDK 데이터 처리에 맞췄다. app-ads.txt에 기존 AdMob 게시자 판매자 확인 레코드를 추가했다.

배포 프로젝트·공개 주소·도메인 및 HTTPS 확인 결과는 배포 후 아래에 기록한다. 지원 메일 실제 수신은 이번 작업에서 테스트하지 않았다. 게임 앱의 스토어 제출은 이 홈페이지 배포 승인 범위에 포함되지 않는다.

## 1차 공개 확인

- 기존 계정의 무료 Cloudflare Pages `pibostudio`에 검증한 `dist` 정적 파일만 직접 배포했다. 1차 배포 ID: 49ae241a-d57d-4490-a1e6-4b5e3a8a897b.
- pibostudio.com apex CNAME만 추가하고 기존 MX·DKIM·SPF 다섯 레코드는 보존했다. 실제 HTTPS 한국어 홈과 영어 정책을 브라우저에서 열어 확인했다.
- 전체 HTML 경로와 robots/app-ads/sitemap/두 RSS의 표준 curl HTTPS 요청은 성공했다. HTML에는 Cloudflare 이메일 보호 변환이 있어 원본 바이트 일치로 표현하지 않는다. Python 기본 클라이언트는 Cloudflare 1010 거절을 받았으나 표준 curl과 실제 브라우저는 정상이다. 보안 설정은 변경하지 않았다.
- 실제 공개 정책 주소를 저승분식 AdMob에 저장하고 해당 iOS 앱 하나의 유럽 동의 메시지를 게시했다. 다른 앱 메시지는 변경하지 않았다.

사용자가 기존 myupyu/pibostudio main의 소스·문서 커밋/푸시 및 자동 배포 연결, www.pibostudio.com 추가 연결도 별도로 명시 승인했다. 기존 직접 업로드 프로젝트는 보존하며 Git 연결 프로젝트가 준비되면 도메인 연결을 검증한다.
